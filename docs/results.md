## 論文の主張との比較

論文の成功判定基準に対する確認結果:

### 1. TabDDPMが総合的に最も性能が良い → **確認**

Green データセットにおいて、TabDDPM は Downstream R²、SDV Score、Wasserstein 距離、Coverage のすべてで他モデルを大幅に上回った。論文の主張と一致する。

### 2. GaussianCopulaは高速だが品質・プライバシーは弱い → **部分的に確認**

GaussianCopula は学習0.1分と圧倒的に高速。ただしGreen N=40,000での本実験結果がないため品質の直接比較は限定的。Zone評価ではCoverageが0.49%と極端に低く、品質面の弱さが確認できる。

### 3. 一部モデルでモード崩壊が発生 → **確認**

CTGAN (Coverage 18.81%) と TVAE (15.76%) は Coverage が極端に低く、データの多様性を再現できていない。これはモード崩壊の兆候と考えられる。一方 TabDDPM は 68.34% と良好。

### 4. グラフ構造で実データとの差が残る → **確認**

Zone評価で全モデルの G_te_syn は 25-31 程度であり、ベースライン (G_tr_te=73.17) に対して大幅に低い。OD構造の再現は依然として課題。

## 結論

本再現実験により、論文の主要な知見を確認できた。**TabDDPM は全指標で最も高い合成データ品質を示し**、特に Downstream R² (95.31) と Coverage (68.34%) において他のGAN/VAEベースモデルを大幅に上回った。一方で学習時間は約35分/回と長く、実用面ではトレードオフがある。CTGAN・TVAE ではモード崩壊の兆候が見られ、グラフ構造 (OD) の再現は全モデルで課題として残った。
